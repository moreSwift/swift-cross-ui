# PreviewsExample

A minimal macOS application project that demonstrates `#Preview` on a
SwiftCrossUI view rendering in Xcode's canvas.

## Why an application project

Xcode only hosts a package view's preview from a target with an application
product type in its active scheme (see the "Where previews appear" table in
`SCUIPreviewMacro.swift`'s documentation, in `Sources/SwiftCrossUIPreviews`).
`Examples/CounterExample` previews its own view fine because the view and the
preview share a module, but it's a package executable target, not an app, so
it can't demonstrate previewing views from elsewhere in the package. This
project exists to prove and preserve that path: an app target depending on
SwiftCrossUI by path.

## Contents

- `project.yml` — [XcodeGen](https://github.com/yonaskolb/XcodeGen) source of
  truth. `PreviewsExample.xcodeproj` is generated from it and not committed
  (see `.gitignore`), so generate it before opening the project:
  ```sh
  xcodegen generate --spec Examples/PreviewsExample/project.yml \
    --project Examples/PreviewsExample
  ```
- `Sources/App.swift` — minimal SwiftUI-lifecycle app, present only to give
  the project an application product type.
- `Sources/PreviewedCounter.swift` — the canonical preview: a small
  `SwiftCrossUI.View` plus a bare `#Preview { Counter() }`, written exactly as
  a consumer would write it (no `#if`, no `@available`, no SwiftUI import).

## How to open it

1. Generate the project (see above) — this also regenerates the shared
   `PreviewsExample` scheme from `project.yml`'s `schemes:` block.
2. Open `PreviewsExample.xcodeproj`.
3. Select the `PreviewsExample` scheme (My Mac destination).
4. Open `Sources/PreviewedCounter.swift` and resume the canvas
   (⌥⌘P, or ⌥⌘⏎ if it's not already showing).

Expect the canvas to render "Count: 0" with a working Increment button.

## Verifying it manually

```sh
xcodegen generate --spec Examples/PreviewsExample/project.yml \
  --project Examples/PreviewsExample
xcodebuild -project Examples/PreviewsExample/PreviewsExample.xcodeproj \
  -scheme PreviewsExample -destination 'platform=macOS' build
```

Run this after changing SwiftCrossUI's public API to confirm the example
still resolves and builds against it. It does not exercise the canvas itself
(preview thunks are generated by the canvas, not by `xcodebuild`) — the
canvas check in "How to open it" above is the only way to confirm previews
actually render; this command only confirms the project still builds.
